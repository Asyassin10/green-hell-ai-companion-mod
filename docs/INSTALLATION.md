# Installation

Install BepInEx 5 x64 Mono, launch Green Hell once, then exit. Start the backend with `Makefile.ps1 qdrant-up` and `Makefile.ps1 api`. Copy `releases\GreenHellAICompanion.dll` into `Green Hell\BepInEx\plugins\` and launch the game. Load a save and press F8.

The DLL is a read-only telemetry and UI client. It does not modify original game assemblies.
